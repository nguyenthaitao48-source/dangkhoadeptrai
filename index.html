Tài liệu tích hợp API BaoStar v2

KHOASMM.COM hỗ trợ chuẩn giao thức API SMM v2 chuẩn quốc tế. Bạn có thể kết nối trang web bán lẻ của mình trực tiếp với KHOASMM.

1. Thông tin Endpoint API
URL API: https://khoasmm.com/api/v2 (hoặc https://baostar.net/api/v2)
Phương thức: POST
Định dạng dữ liệu: application/x-www-form-urlencoded
2. API Key của bạn
Mzk5NzVub3diZDg1MzBkODRlNzBjMjMyYTkzNmViMGZk
3. Ví dụ gửi đơn hàng (cURL)
curl -X POST https://khoasmm.com/api/v2 \
  -d "key=Mzk5NzVub3diZDg1MzBkODRlNzBjMjMyYTkzNmViMGZk" \
  -d "action=add" \
  -d "service=16379" \
  -d "link=https://www.tiktok.com/@khoasmm" \
  -d "quantity=100"
